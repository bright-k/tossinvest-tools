# 검증 계획

기본 개발 검증은 실제 토스 접속·키·Keychain과 독립적으로 수행합니다. endpoint 이름만 반복하는 테스트보다 요청 직렬화, 응답 의미, 권한과 주문 실패 복구를 검증합니다. 실제 존재하는 테스트 경로와 실행 결과를 API 대응 데이터·인수인계에 연결합니다.

## 생성 코드와 fixture

R1 수용 검증은 인증·34개 조회·로컬 접속·readonly 차단과 기능별 준비를 우선합니다. T-013~T-023 등 실주문 관련 전체 검증은 P4 이후에 연결합니다. P0의 전체 타입 생성과 readonly의 직접 전송 차단은 주문 모듈과 무관하게 먼저 검증합니다. WS 수용 검증은 R2, 6개 실제 쓰기 업무는 T1의 완료 조건입니다.

T-039~T-042는 R1, T-043~T-044는 R2 종료 기준입니다. 위 경계값은 [ADR 0004](decisions/0004-readonly-access-and-event-history.md)의 로컬 정책이며 fake clock·임시 DB·가짜 UID/credential provider·로컬 모의 HTTP/WS로 검증합니다. 실제 Keychain/OS peer UID 연동은 별도 opt-in 검증입니다. 실제 계좌 제한 전제가 확인되지 않은 기능은 live-verified로 표시하지 않습니다.

원본의 예제를 활용해 decode 성공·null·필수 항목·실제 필드명을 확인합니다. 예제만으로 모든 실제 상황을 커버했다고 판단하지 않습니다. 각 업무의 제약과 오류를 추가 검증하며, 계좌 응답을 저장할 때는 개인 정보를 제거합니다. 토스의 실제 비밀을 fake 값처럼 fixture에 넣지 않습니다.

생성 코드 자체의 getter나 복사된 상수를 반복 검증하지 않습니다. 네트워크 경계의 form/JSON·헤더·decimal·타입 조합과 실제 업무 영향에 집중합니다. 응답의 추가 필드는 허용하면서 필수 데이터의 의미적 손상은 거부합니다.

## 테스트 실행 계약

Go 모듈과 테스트를 만든 뒤 다음을 기본 검증으로 제공합니다. 현재 실행 대상과 검증 결과가 있으며 [실행 기록](verification/README.md)에 명령·결과·대기 범위를 기록했습니다.

```text
go test ./...
go test -race ./...
go vet ./...
```

명세 검사는 `make check`, 재생성 일치는 `make check-generated`, 독립 서버 프로토콜은 `make mcp-check`, 실제 설치 Codex 발견은 `make codex-check`, TTY 설정은 `make cli-check`를 사용합니다. 테스트는 기본적으로 외부 네트워크·실제 Keychain을 사용하지 않습니다. 토큰·WS 시각·멱등시간은 가짜 시계로 재현하여 긴 sleep이나 실시간 시장에 의존하지 않게 합니다.

## 실제 환경 검증

실제 조회와 실주문은 기본 자동 테스트의 일부가 아닙니다. 사용자가 허용한 계좌·작업·시간·한도와 결과를 따로 기록하며 비밀이나 실제 식별자를 Git에 남기지 않습니다. 단순 주문 후 취소도 체결될 수 있으므로 안전한 무부작용 테스트로 간주하지 않습니다.

실제 조회의 통과는 실주문 검증이 아니고, 특정 계좌의 실주문 통과는 모든 계좌·종목·세션의 거래 보증이 아닙니다. 원본 클라이언트 검증, 업무 수용 검증, 실제 연결 검증을 구분합니다.

## CLI 업무 조회 확장 수용

`internal/cli/query_test.go`와 `internal/runtime/query_test.go`는 T-003/004/006/008/009/010/011/038에 대해 accounts·holdings·prices의 성공·필수/부적절 입력·미선택/철회 계좌·마스킹·접속 credential 실패·필터/서버 주입 계좌 헤더·원본 오류·큰 정수/Decimal/null·서버 부재와 비로컬 credential 전송 거부를 검증한다. `make cli-check`는 빌드한 CLI를 실제 프로세스로 실행해 같은 세 조회와 철회/서버 미실행을 확인한다. 상세 결과는 [CLI 조회 검증](verification/cli-queries.md)이다.
